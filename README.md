# Bilder für Instagram-Beiträge

Hier liegen die fertigen Beitragsbilder, damit Instagram sie abholen kann.
Instagram lädt keine Bilder hoch, es holt sie von einer Adresse im Netz.

Nach dem Veröffentlichen speichert Instagram das Bild selbst — die Kopie hier
wird dann gelöscht. Deshalb bleibt der Ordner fast leer.

Keine Personendaten, keine Kundennamen, nur Werbebilder.
